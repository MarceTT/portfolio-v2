# OG Image Design Brief

## Especificaciones Técnicas
- **Tamaño**: 1200 x 630 px
- **Formato**: PNG
- **Nombre archivo**: `og-image.png`

## Propósito
Imagen de preview para redes sociales (Facebook, LinkedIn, Twitter, WhatsApp) cuando alguien comparta el link del portfolio.

## Marca
- **Nombre**: Marcelo Toro
- **Tagline**: Software & Automatización
- **Subtítulo opcional**: Desarrollo a medida | Consultoría técnica

## Estilo Visual
- **Tema**: Dark mode, moderno, profesional, tech
- **Colores principales**:
  - Fondo: Negro/gris muy oscuro (`#0a0a0a` o `#111111`)
  - Texto principal: Blanco (`#ffffff`)
  - Acento: Gradiente violeta/azul/rosa (similar a: `from-purple-500 via-blue-500 to-pink-500`)
- **Tipografía**: Sans-serif moderna, bold para el nombre
- **Estética**: Minimalista, limpia, con un toque de gradiente para destacar

## Elementos a Incluir
1. **Nombre "Marcelo Toro"** — grande, prominente, en blanco
2. **"Software & Automatización"** — más pequeño, puede tener el gradiente de color
3. **Elementos decorativos opcionales**:
   - Líneas de código sutiles en el fondo (muy tenues)
   - Formas geométricas abstractas
   - Efecto de glow/aurora sutil (como el sitio web)

## Referencia
El sitio web usa:
- Aurora background con gradientes
- Componentes de Inspira UI
- Estética dark mode moderna

## NO Incluir
- Foto personal (a menos que se vea muy profesional)
- Demasiado texto
- Colores brillantes que no combinen con el tema oscuro
- Logos de tecnologías
